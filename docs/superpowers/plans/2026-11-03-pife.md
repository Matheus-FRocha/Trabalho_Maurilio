# Pife/Caxeta Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task-by-task, com TDD e revisão final.

**Goal:** entregar jogo web para dois jogadores e evidência real de IPC compartilhado.
**Architecture:** domínio puro, serviço por sala com lock, STOMP privado, cliente React e monitor NIO.
**Tech Stack:** Java 21, Spring Boot, Maven, JUnit 5, React, Vite, Tailwind, STOMP, Playwright.
**Spec:** docs/superpowers/specs/2026-11-03-pife-design.md

## Global Constraints
Preservar LICENSE/origin; apenas esta pasta. Sem banco. Sem credenciais no Git.
Não desenvolver em main. Testar antes de integrar e publicar. Regras aprovadas na documentação.

## Review Focus
Identidade falsificada e assinaturas a destinos alheios devem ser recusadas.
Compra simultânea/repetida deve alterar estado uma única vez.
Reconexão não deve perder mão nem dar ao socket antigo controle de outra sessão.
Sala expirada deve liberar estado e tokens/snapshots associados.
Falha do espelho IPC não deve reaplicar uma jogada já efetivada.
